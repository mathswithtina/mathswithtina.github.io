The SAT doesn't invent hard algebra. It takes straightforward concepts and adds one predictable twist — a sign flip, a hidden negative root, a missed absolute value branch. If you know the traps, you see them coming.

## Trap 1: Forgetting the ± on square roots

**x² = 25** → x = ±5, NOT just x = 5.

The SAT often frames this as a word problem where the answer seems like it should be positive. Unless you're told x > 0, always consider both roots.

## Trap 2: Distributing incorrectly

**−3(x − 4) = −3x + 12**, NOT −3x − 12.

A negative multiplying a negative gives a positive. This error alone accounts for a huge fraction of wrong answers in algebra sections.

## Trap 3: Absolute value has two cases

**|x − 3| = 7** → x − 3 = 7 or x − 3 = −7 → x = 10 or **x = −4**.

The SAT loves setting up absolute value equations where students solve only the positive case.

## Trap 4: Substituting back incorrectly

After solving a system, always substitute back to verify. If a + b = 5 and ab = 6, and you want a² + b², don't solve for individual values — use (a + b)² − 2ab = 25 − 12 = **13**.

## Trap 5: Exponent rules confusion

- (x²)³ = x⁶ (multiply exponents) — NOT x⁵
- x² · x³ = x⁵ (add exponents) — NOT x⁶
- (2x)³ = 8x³ — the 2 is raised too!

## The "integer vs. any real number" trap

The SAT often shows fractions in disguise. If 3x = 5, then x = 5/3 — a valid answer. Don't assume the answer must be a whole number just because the problem looks clean.
