<div class="lang-block lang-en">
<p>The SAT doesn't invent hard algebra. It takes straightforward concepts and adds one predictable twist — a sign flip, a hidden negative root, a missed absolute value branch. If you know the traps, you see them coming.</p>

<h2>Trap 1: Forgetting the ± on square roots</h2>

<p><strong>x² = 25</strong> → x = ±5, NOT just x = 5.</p>

<p>The SAT often frames this as a word problem where the answer seems like it should be positive. Unless you're told x &gt; 0, always consider both roots.</p>

<h2>Trap 2: Distributing incorrectly</h2>

<p><strong>−3(x − 4) = −3x + 12</strong>, NOT −3x − 12.</p>

<p>A negative multiplying a negative gives a positive. This error alone accounts for a huge fraction of wrong answers in algebra sections.</p>

<h2>Trap 3: Absolute value has two cases</h2>

<p><strong>|x − 3| = 7</strong> → x − 3 = 7 or x − 3 = −7 → x = 10 or <strong>x = −4</strong>.</p>

<p>The SAT loves setting up absolute value equations where students solve only the positive case.</p>

<h2>Trap 4: Substituting back incorrectly</h2>

<p>After solving a system, always substitute back to verify. If a + b = 5 and ab = 6, and you want a² + b², don't solve for individual values — use (a + b)² − 2ab = 25 − 12 = <strong>13</strong>.</p>

<h2>Trap 5: Exponent rules confusion</h2>

<ul>
  <li>(x²)³ = x⁶ (multiply exponents) — NOT x⁵</li>
  <li>x² · x³ = x⁵ (add exponents) — NOT x⁶</li>
  <li>(2x)³ = 8x³ — the 2 is raised too!</li>
</ul>

<div class="insight-box">
  <p><strong>The SAT meta-skill:</strong> On any problem, ask yourself "what trap is this testing?" before you solve it. Usually the trap is obvious once you're looking for one. Speed comes from recognition, not calculation.</p>
</div>

<h2>The "integer vs. any real number" trap</h2>

<p>The SAT often shows fractions in disguise. If 3x = 5, then x = 5/3 — a valid answer. Don't assume the answer must be a whole number just because the problem looks clean.</p>

<div class="try-it">
  <h3>Practice — spot the trap</h3>
  <p>If x² − 5x = 0, what are all values of x?</p>
  <button class="reveal-btn">Show Answer</button>

    <p><strong>Trap:</strong> Many students divide both sides by x, losing the solution x = 0. Never divide by a variable unless you know it's nonzero.</p>

<div class="lang-block lang-ka">
<p>SAT არ იგონებს რთულ ალგებრას. ის იღებს მარტივ ცნებებს და ამატებს ერთ პროგნოზირებად გადახვევას — ნიშნის შეცვლა, ფარული უარყოფითი ფესვი, მოდულის გამოტოვებული ტოტი. თუ ხაფანგებს იცნობ, წინასწარ ხედავ.</p>

<h2>ხაფანგი 1: ± დავიწყება კვადრატულ ფესვებში</h2>

<p><strong>x² = 25</strong> → x = ±5, არა მხოლოდ x = 5.</p>

<p>SAT ხშირად ამას სიტყვიერ ამოცანად აყალიბებს, სადაც პასუხი დადებითი ჩანს. თუ არ გეთქვა x &gt; 0, ყოველთვის განიხილე ორივე ფესვი.</p>

<h2>ხაფანგი 2: მცდარი განაწილება</h2>

<p><strong>−3(x − 4) = −3x + 12</strong>, არა −3x − 12.</p>

<p>უარყოფითი გამრავლებული უარყოფითზე დადებითს იძლევა. ეს შეცდომა მარტო ბევრი მცდარი პასუხის მიზეზია ალგებრის სექციაში.</p>

<h2>ხაფანგი 3: მოდულს ორი შემთხვევა აქვს</h2>

<p><strong>|x − 3| = 7</strong> → x − 3 = 7 ან x − 3 = −7 → x = 10 ან <strong>x = −4</strong>.</p>

<p>SAT გიყვარს მოდულის განტოლებები, სადაც მოსწავლეები მხოლოდ დადებით შემთხვევას ხსნიან.</p>

<h2>ხაფანგი 4: მცდარი ჩასმა უკან</h2>

<p>სისტემის ამოხსნის შემდეგ ყოველთვის ჩასვი უკან შესამოწმებლად. თუ a + b = 5 და ab = 6, და გინდა a² + b², ნუ ხსნი ცალ-ცალკე — გამოიყენე (a + b)² − 2ab = 25 − 12 = <strong>13</strong>.</p>

<h2>ხაფანგი 5: ხარისხის წესების აღრევა</h2>

<ul>
  <li>(x²)³ = x⁶ (გაამრავლე ხარისხები) — არა x⁵</li>
  <li>x² · x³ = x⁵ (შეაკრიბე ხარისხები) — არა x⁶</li>
  <li>(2x)³ = 8x³ — 2-ც იხარისხება!</li>
</ul>

<div class="insight-box">
  <p><strong>SAT-ის მეტა-უნარი:</strong> ნებისმიერ ამოცანაზე კითხე საკუთარ თავს "რომელ ხაფანგს ამოწმებს ეს?" ამოხსნამდე. ჩვეულებრივ, ხაფანგი ნათელია, როდესაც ეძებ. სიჩქარე მოდის ამოცნობიდან, არა გამოთვლიდან.</p>
</div>

<h2>"მთელი vs. ნებისმიერი რეალური" ხაფანგი</h2>

<p>SAT ხშირად ფარავს წილადებს. თუ 3x = 5, მაშინ x = 5/3 — ვალიდური პასუხია. ნუ ივარაუდებ, რომ პასუხი მთელი რიცხვი უნდა იყოს, მხოლოდ იმის გამო, რომ ამოცანა სუფთად გამოიყურება.</p>
