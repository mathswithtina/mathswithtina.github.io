<div class="lang-block lang-en">
<p>Most triangles are not right-angled. The sine rule and cosine rule extend trigonometry to <strong>all triangles</strong> — and they appear in almost every IB and A-Level exam.</p>
<p>Label your triangle: sides a, b, c opposite to angles A, B, C respectively.</p>

<h2>The Sine Rule</h2>
<p><strong>a/sinA = b/sinB = c/sinC</strong></p>
<p>Use when you have: <strong>AAS</strong> (two angles, one side) or <strong>ASS</strong> (two sides, the angle opposite one of them).</p>
<p><strong>Example:</strong> In △ABC, A = 35°, B = 72°, a = 8. Find b.</p>
<p>b/sin72° = 8/sin35° → b = 8·sin72°/sin35° ≈ <strong>13.3</strong></p>

<h2>The Cosine Rule</h2>
<p><strong>c² = a² + b² − 2ab cosC</strong></p>
<p>Use when you have: <strong>SAS</strong> (two sides and included angle) or <strong>SSS</strong> (all three sides).</p>
<p><strong>Example:</strong> a = 5, b = 8, C = 110°. Find c.</p>
<p>c² = 25 + 64 − 80cos(110°) = 89 + 27.36 ≈ 116.4 → c ≈ <strong>10.8</strong></p>
</div>

<div class="lang-block lang-ka">
<p>სამკუთხედების უმეტესობა მართკუთხა არ არის. სინუსებისა და კოსინუსების თეორემები ტრიგონომეტრიას <strong>ყველა სამკუთხედამდე</strong> აფართოებს — და ისინი IB და A-Level თითქმის ყველა გამოცდაში გამოჩნდება.</p>
<p>დაასახელე სამკუთხედი: გვერდები a, b, c შესაბამისად A, B, C კუთხეების მოპირდაპირედ.</p>

<h2>სინუსების თეორემა</h2>
<p><strong>a/sinA = b/sinB = c/sinC</strong></p>
<p>გამოიყენე, როდესაც გაქვს: <strong>AAS</strong> (ორი კუთხე, ერთი გვერდი) ან <strong>ASS</strong> (ორი გვერდი, ერთ-ერთის მოპირდაპირე კუთხე).</p>
<p><strong>მაგალითი:</strong> △ABC-ში, A = 35°, B = 72°, a = 8. იპოვე b.</p>
<p>b/sin72° = 8/sin35° → b = 8·sin72°/sin35° ≈ <strong>13.3</strong></p>

<h2>კოსინუსების თეორემა</h2>
<p><strong>c² = a² + b² − 2ab cosC</strong></p>
<p>გამოიყენე, როდესაც გაქვს: <strong>SAS</strong> (ორი გვერდი და მოქცეული კუთხე) ან <strong>SSS</strong> (სამივე გვერდი).</p>
<p><strong>მაგალითი:</strong> a = 5, b = 8, C = 110°. იპოვე c.</p>
<p>c² = 25 + 64 − 80cos(110°) = 89 + 27.36 ≈ 116.4 → c ≈ <strong>10.8</strong></p>
</div>

<div class="insight-box">
  <p><strong>The ambiguous case:</strong> When using the sine rule to find an angle (SSA case), you might get two possible triangles (an acute and obtuse angle both fit). Always check both and discard any that make the angles add up to more than 180°.</p>
</div>

<h2>Area of a triangle</h2>
<p><strong>Area = (1/2) ab sinC</strong></p>
<p>where C is the angle between sides a and b. This is the formula for triangles where the height isn't given directly.</p>

<h2>სამკუთხედის ფართობი</h2>
<p><strong>ფართობი = (1/2) ab sinC</strong></p>
<p>სადაც C არის კუთხე გვერდებ a და b-ს შორის. ეს ფორმულა გამოიყენება სამკუთხედებისთვის, სადაც სიმაღლე პირდაპირ მოცემული არ არის.</p>
